# 📄 Documentation : `nlp/TechStackDetector.java`

## 📌 Rôle du Fichier
`nlp/TechStackDetector.java` identifie les technologies logicielles, langages de programmation, frameworks, contextes académiques et langues cibles mentionnés dans le prompt.

---

## 💻 Les 12 Familles Technologiques Reconnues

1. **Java & JVM** : Java, Spring Boot, Quarkus, Maven, Gradle, Hibernate...
2. **Python & Data** : Python, Django, FastAPI, Flask, Pandas, NumPy, PyTorch, TensorFlow...
3. **JavaScript & TypeScript** : JS, TS, Node.js, React, Vue, Angular, Next.js, Svelte...
4. **C & C++** : C, C++, STL, Pointers, CMake, GCC, Clang, Boost...
5. **C# & .NET** : C#, .NET, ASP.NET, Entity Framework, Unity...
6. **Rust & Go** : Rust, Cargo, Tokio, Go, Golang, Goroutines...
7. **PHP & Web Backend** : PHP, Laravel, Symfony, WordPress...
8. **HTML, CSS & UI Design** : HTML5, CSS3, Tailwind CSS, Bootstrap, Sass, Figma, Flexbox, Grid...
9. **Bases de Données & SQL** : SQL, PostgreSQL, MySQL, SQLite, MongoDB, Redis, Oracle...
10. **DevOps, Cloud & Conteneurs** : Docker, Kubernetes, AWS, GCP, Azure, Terraform, CI/CD, Linux, Bash...
11. **Mobile (iOS & Android)** : Swift, Kotlin, Flutter, React Native, iOS, Android...
12. **Jeux Vidéo & Graphisme** : Unreal Engine, Unity, Godot, OpenGL, Vulkan, DirectX, Shader...

---

## 🌐 Détections Spéciales
* `detecterLangueCibleTraduction(String text)` : Extrait la langue cible lors d'instructions de traduction (ex: `"traduire en anglais"`, `"vers l'espagnol"`, `"vers le japonais"`).
* `detecterContexteSpecial(String text)` : Détecte des contextes académiques spécifiques (ex: `42 School`, `EPITECH`, `Recherche / Thèse`).

---

## 👨‍💻 Exemple d'Utilisation

```java
List<String> technos = TechStackDetector.detecter("Créer un backend FastAPI avec PostgreSQL et Docker");
System.out.println(technos); // ["Python", "SQL", "DevOps & Cloud"]
```
